# Archipelago - Elden Ring Nightreign

This is an [Archipelago](https://archipelago.gg/) implementation for **Elden Ring Nightreign**, currently in
**beta**. See [Overview](worlds/nightreign/docs/en_Nightreign.md) for what the
client does, and [setup](worlds/nightreign/docs/setup.md) for setup instructions.  Check out our [roadmap](worlds/nightreign/docs/roadmap.md).

## Status

This is an beta, currently getting feedback on the core implementation to make something everyone enjoys.


## Running the Client

- Run the game with **anti-cheat disabled**.
- For best results, connect the client while at the hub (Roundtable Hold), and after any cutscenes have finished.

## Reporting Issues

Found a bug or a boss that isn't detected correctly? Please report it:

- On Discord: message **jacksontc** on the appropriate channel in the Archipelago server, or
- On [GitHub](../../issues), by opening an issue.
